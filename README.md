# Лабораторная работа №1 — Продвинутый калькулятор

Приложение для iOS на Swift и SwiftUI. Минимальная версия iOS — 17.0.
Внешние библиотеки и сетевые сервисы не используются.

## Запуск в Xcode

1. Откройте `AdvancedCalculator.xcodeproj`.
2. Выберите схему `AdvancedCalculator` и симулятор iPhone или iPad.
3. Нажмите **Run** (`⌘R`). Для симулятора аккаунт разработчика не нужен.
4. Для запуска на физическом устройстве выберите свой Team в Signing & Capabilities.

## Возможности и соответствие ТЗ

| Требование | Реализация |
| --- | --- |
| Полноценное выражение | Ввод кнопками или редактирование поля, включая вставку текста |
| +, −, ×, ÷ | Поддерживаются также символы `-`, `*`, `/` при ручном вводе |
| Вещественные числа | Точка или запятая, например `15.5×2` или `15,5×2` |
| Приоритет и скобки | Умножение и деление раньше сложения и вычитания; вложенные скобки |
| = | Вычисляет всё выражение; результат показан отдельно |
| C | Очищает выражение, последний результат и ошибку |
| ⌫ | Удаляет последний символ текущего выражения |
| % | Постфиксный процент: `50%=0.5`, `200×10%=20` |
| ± | Меняет знак последнего числа или выражения в скобках |
| История | Последние 10 успешных вычислений, новые сверху |
| Повтор из истории | Нажатие возвращает выражение для редактирования и вычисления |
| M+, M− | Вычисляют текущее выражение и добавляют/вычитают значение из памяти |
| MR | Вставляет память; после результата начинает новый ввод |
| MC | Обнуляет память |
| Сохранение состояния | Выражение, история, память, результат и ошибка в UserDefaults |
| Поворот | Модель сохраняется; в альбомной ориентации история видна рядом |
| Ошибки | Понятное сообщение без аварийного завершения |
| Независимая логика | `ExpressionEvaluator` не зависит от SwiftUI; есть отдельные тесты |

Процент трактуется как деление на 100, поскольку контекстный процент в ТЗ не задан.
Например, `100+10%=100.1`; чтобы прибавить 10% от 100, введите `100+100×10%`.

Отрицательный операнд после арифметического оператора записывается в скобках:
`2×(−3)`. Кнопка `±` сама добавляет нужные скобки. `2×−3` считается двумя
операторами подряд и показывает ошибку, как требует ТЗ.

После `=` нажатие арифметического оператора продолжает вычисление с полученным
результатом; нажатие цифры начинает новое выражение. Поле выражения можно
редактировать системной клавиатурой. История открывается кнопкой с часами.
Очистка ввода не удаляет историю и память.

## Архитектура

- `Sources/CalculatorCore/ExpressionEvaluator.swift`: лексический анализатор,
  рекурсивный разбор выражения и ошибки. Разбор выполняется по уровням:
  сумма → произведение → число/скобки с процентом.
- `Sources/CalculatorCore/CalculatorStore.swift`: состояние, история, память,
  действия кнопок и сохранение всех данных одним JSON в UserDefaults.
- `Sources/AdvancedCalculator/ContentView.swift`: адаптивный интерфейс и история.
- `Sources/AdvancedCalculator/AdvancedCalculatorApp.swift`: единственная модель
  приложения и сохранение при уходе в фон.
- `Tests/CalculatorCoreTests`: независимые XCTest-тесты вычислений и модели.
- `Package.swift`: позволяет тестировать вычисления и состояние без iOS-интерфейса.

Неверные выражения не попадают в историю и не изменяют память. После редактирования
ошибка снимается. Используется Double с выводом до 15 значащих цифр. Научная запись
поддерживается, чтобы очень маленькие и большие результаты оставались корректным
вводом. Деление на ноль, переполнение и чрезмерная вложенность обнаруживаются.

## Проверка

Из этой папки:

```sh
swift test --scratch-path /tmp/AdvancedCalculatorTests
```

Выполнены 13 тестов, все прошли. Они проверяют примеры из ТЗ, приоритет,
ассоциативность, вложенные скобки, дробные числа, проценты, отрицательные числа,
все обязательные ошибки, ограничение истории, возврат выражения, память,
сохранение пяти обязательных полей и продолжение вычисления после результата.
Приложение успешно собрано для iOS Simulator и запущено из Xcode на iPhone 18 Pro.

Короткие сценарии для демонстрации:

1. `12+5×3` → `27`; `(12+5)×3` → `51`.
2. `15.5×2` → `31`; `20÷4+7` → `12`.
3. `50%` → `0.5`; введите `12+5`, нажмите `±`, затем `=` → `7`.
4. `10`, `M+`; очистить ввод; `3`, `M−`; очистить ввод; `MR` → `7`; `MC` → память `0`.
5. Вычислите 11 выражений: в истории останутся последние 10. Нажмите любое,
   измените выражение и вычислите снова.
6. Проверьте `1÷0`, `(1+2`, `1++2`, `1..2`, пустое выражение и `1+`: появляется ошибка.
7. Введите выражение, заполните память/историю, поверните устройство: данные сохраняются.
   Затем вызовите ошибку, закройте и откройте приложение: ошибка тоже сохраняется.
